# پوشهٔ دیتا

فایل‌های ورد (`.docx`) خودت را اینجا بریز.

هر فایل یک منبع است — می‌تواند اسکریپت ویدیو، جزوهٔ درسی، مستندات کار، یا هر متنی باشد که می‌خواهی ایجنت از رویش جواب بدهد.

بعد از گذاشتن فایل‌ها، `python ingest.py` را اجرا کن تا ایندکس ساخته شود.

---

Put your Word (`.docx`) files here — one file per source.
Then run `python ingest.py` to build the index.
